**Project Title**

House Price Prediction using Machine Learning

**Problem Statement**

Predicting house prices based on various features such as location, number of rooms, and area can help buyers and sellers make informed decisions.

**Dataset**
Housing dataset containing features such as:
Area
Number of bedrooms
Bathrooms
Stories
Parking
**Technologies Used**
Python
Pandas
NumPy
Scikit-Learn
Streamlit
**Model Used**
Linear Regression
**Results**
Developed a model that predicts house prices based on input features
Built an interactive Streamlit web application for price prediction
